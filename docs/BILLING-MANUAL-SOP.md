# 金流人工處理流程：退款、重寄發票、加購則數

> 給老闆與會計看的操作流程。系統目前**沒有**自動退款、重寄發票、加購收款的按鈕，這三件事先照這份人工處理。
> 拍板：2026-10-20 老闆「照建議」（STATUS `B-11`、`B-30`、`D-6`）。哪天做成按鈕，這份跟著改。
> 對外的承諾以[退費政策](https://lineminime.com/refund)與[服務條款](https://lineminime.com/terms)為準，這份只講「內部怎麼做到」。

下面說的「超管」是 MiniMe 的超級管理員帳號（目前兩位：service@myfeel-tw.com、splash.digilab@gmail.com）。MiniMe 這邊的動作都要用超管帳號做。

## 一、客戶要退款

**先判斷要不要退**（退費政策頁寫的）：只有這幾種情況會退——重複扣款／金額錯誤、非本人刷卡、我們這邊故障連續超過 72 小時沒修好、我們終止服務。當期費用、沒用完的額度、自己降級，都不退。

**能用折抵就先用折抵**：客戶還要繼續用的話，經他同意改成「下期少收」最乾淨——不用退錢、不用動發票。
- MiniMe 超管 →「金流總覽」→ 那個帳號那一列 →「開折抵」→ 填金額、原因 → 確認。
- 下一期自動扣款時直接少收；發票開的就是少收後的金額，原發票完全不動。

**要退回信用卡時**（政策承諾：確認符合條件後 **7 個工作日內**送出退款）：

| 步驟 | 誰做 | 在哪裡做 |
|---|---|---|
| 1. 確認退多少、為什麼（整期還是部分；按日比例的算法在退費政策頁） | 老闆 | — |
| 2. 實際把錢退回客戶的信用卡 | 有 PAYUNi 商店後台權限的人 | PAYUNi 商店後台，對那一筆交易做退款。訂單編號在 MiniMe「金流總覽」那一列 |
| 3. 回 MiniMe 留紀錄 | 超管 | 「金流總覽」→ 那一列 →「記退款」→ 填金額、原因。⚠️ 這顆**只記帳、不會退錢**，一定要先做完第 2 步 |
| 4. 處理發票 | 超管（會計確認用哪一種） | 同一列：**整筆退、而且還在作廢期限內**（B2C 開立隔天起 2 天、B2B 7 天內，且當期還沒申報）→「作廢」填原因；**部分退，或已經過了作廢期限** →「折讓」填金額與原因（抬頭統編系統會照原發票帶） |
| 5. 不再續用的話，停掉之後的自動扣款 | 客戶自己，或請工程協助 | 客戶在後台「訂閱與付款」按「取消訂閱」（本期用到期末、之後不再扣）。⛔ 不要直接在超管把訂閱狀態改成取消——那樣會讓到期處理出錯，要停請找工程 |

- 金流手續費不從退款金額扣（政策頁寫的）。
- 會計對帳看哪裡：「金流總覽」那一列會標「已退款／部分退款」「已作廢／已折讓」，點發票號碼看得到明細與折讓紀錄。

## 二、客戶說沒收到發票、或發票寄錯信箱

系統沒有「重寄發票」的按鈕，光貿也沒有提供重寄的 API，只能人工處理。

1. **先查這張發票有沒有開成功**：MiniMe 超管 →「金流總覽」→ 點那一列的發票號碼，看得到號碼、隨機碼、開給誰。
2. **請光貿重寄**：登入光貿商家後台，找到那張發票，按「補發發票開立通知」。
3. **信箱填錯的**：請客戶在 MiniMe 後台「訂閱與付款」把發票 Email 改對，之後開的發票才會寄對；這一張如果光貿只能寄回原信箱，就把第 1 步看到的**發票號碼＋隨機碼＋金額**直接回覆給客戶，他可以用這三樣去財政部電子發票平台查到。
4. **抬頭／統編開錯要重開**：走「一、退款」第 4 步的「作廢」，再請工程協助重開（目前沒有自助重開的按鈕）。

## 三、客戶要加購 AI 則數

**現況**：額度用完時，需要 AI 回答的訊息會轉給真人，自動回應照常；系統**不會**自動加收費用。條款寫的是可以「與我們聯繫加購」、「經你同意後才會開通與收費」，現行單價**每則新臺幣 1.5 元**（以條款當下寫的為準）。

| 步驟 | 誰做 | 怎麼做 |
|---|---|---|
| 1. 確認要加幾則、在哪一期用 | 老闆 | 客戶來信或 LINE 詢問 |
| 2. 報價並取得客戶**書面同意** | 老闆 | 則數 × 每則 1.5 元；同意的信件或 LINE 截圖留存 |
| 3. 收款、開發票 | 會計 | 系統沒有加購結帳，照公司現行的人工收款方式（例如匯款），收到款後在光貿後台手動開立發票 |
| 4. 開通額度 | 超管 | 「官方帳號管理」→ 編輯那個帳號 →「額度覆蓋」填「**原本方案的則數＋加購的則數**」；「備註」寫「加購 N 則、到 YYYY-MM-DD、收款單號」 |
| 5. ⚠️ **到期要手動拿掉** | 超管 | 「額度覆蓋」**不會自己到期**（只有降回免費方案時才會清掉）。本期結束那天要回去把它清空，不然等於永久送。開通當天就把清空日期排進行事曆 |

## 還沒做成按鈕的原因

- 退款要打 PAYUNi 的退款 API，寫錯會直接動到客戶的錢；初期量少，人工處理比較安全。量變多再做成一顆按鈕，一次完成「退款＋記帳＋發票」（STATUS `B-11`）。
- 重寄發票要等自家寄信功能穩定後再做（STATUS `B-30`、`B-50`）。
- 加購要先決定收款方式，才做得成自助結帳（STATUS `D-6`）。
