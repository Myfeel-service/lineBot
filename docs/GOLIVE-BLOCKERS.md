### B1. 光貿正式金鑰

- **要三個值**:`GUANGMAO_INVOICE_SELLER_UBN`(賣方統編)、`GUANGMAO_INVOICE_APP_KEY`、`GUANGMAO_INVOICE_API_URL`(正式 = `https://invoice-api.amego.tw`)。
- **哪裡拿**:公司已在用光貿 → 跟內部要現成的統編 + App Key(已決定共用同一帳號,同字軌由光貿統一配號不會撞號);要新開才找光貿客服 `lin.ee/qKyeysc`。
- **現況（2026-07-30）**:本機 `.env` 已填**光貿公開測試帳號**（統編 `12345678`）→ 本機可以完整測發票。
  ⚠️ **生產（Amplify）仍未設** → 真客戶每筆訂單的發票狀態都是 `skipped`,**等於零開票**。
  ⚠️⚠️ **公開測試帳號絕對不能上生產** —— 真客戶的發票會開到測試平台,那是稅務問題。
- ⚠️ `API_URL` 刻意沒有預設值:預設成正式站的話,沙盒測試會把測試發票開到正式平台。
- **不急於今天**:沙盒公開測試帳號可以繼續測作廢/折讓。但**只要開始對真客戶收錢,這個就必須先設好**——收了錢沒開發票是稅務問題。

### B2. 方案價含稅還是未稅(**要會計一句話**)

- 我目前**按含稅實作**:399 = 銷售額 380 + 稅額 19。
- 你的回答是「應該是含稅」→ 已與實作一致,但**請會計正式確認一次**,因為這會影響已經開出去的發票。

### B3. 全額折抵那一期不開發票,會計認不認

**用一個具體例子講**:

| 時間 | 發生什麼 | 發票 |
|---|---|---|
| 7 月 | 客戶付 799 買「入門」方案 | ✅ 我們開了一張 **799** 的發票 |
| 8 月 | 因為某個原因(例如服務中斷賠償),我們決定補他 **400 元**。老闆拍板:**不退現金,改成折抵下期** | — |
| 9 月 | 該扣 399(他降到「輕量」)。有 400 可折 → **399 全部被折光,這個月他不用付錢** | ❓ 要不要開發票? |

**我的做法:9 月不開發票。**

**為什麼**:那 400 元是「7 月那筆 799 裡面的錢」,7 月已經開過發票、也已經報過稅了。
9 月只是把那筆已收的錢拿來抵,**沒有任何新的錢進到公司**。
如果 9 月還為它開一張 399 的發票,等於**同一筆錢開了兩次發票、銷售額被報了兩次**。

**所以要問會計的就是**:「這樣不開,對嗎?」

若會計說不行,替代做法有兩條,但都更麻煩:
1. 開一張 0 元發票(不確定財政部認不認)
2. 改成真的退現金 400 給客戶 + 對 7 月那張發票開折讓(要動退款 API,而且跨月只能走折讓)

## 🟠 C. 擋住「通知信真的寄出去」

程式已經寫好(付款收據、扣款失敗提醒、續扣前提醒、額度快用完),但**沒有設定就是靜默不寄**,
金流流程完全不受影響。

### C1. SES 驗證網域 + 出 sandbox — 白話文

**問題是什麼**:AWS 的寄信服務(SES)新帳號一開始是「**沙盒模式**」,它只准你寄給
「你自己已經驗證過的信箱」。要寄給**任何客戶**,必須跟 AWS 申請「離開沙盒」。

**要做兩件事,都在 AWS Console → Amazon SES**:

1. **驗證寄件網域**(Verified identities → Create identity → Domain,填 `myfeel-tw.com`)
   AWS 會給你**幾筆 DNS 記錄**(CNAME),要加到網域的 DNS 設定裡。加完 AWS 自動驗證通過。
   → 這一步是在證明「這個網域真的是你的」,不然任何人都能冒用你的網域寄信。
2. **申請離開沙盒**(Account dashboard → Request production access)
   填一個表單:你要寄什麼信、怎麼處理退訂與退信。通常 1 個工作日內核准。

### C2. `EMAIL_FROM` / `AWS_SES_REGION` — 白話文

C1 做完之後,把兩個值填進 Amplify 的環境變數:

- **`EMAIL_FROM`** = 客戶收到信時看到的寄件人。格式可帶顯示名稱,例如 `MiniMe <noreply@myfeel-tw.com>`。
  ⚠️ 這個信箱的**網域必須是 C1 驗證過的那個**,否則 SES 直接拒寄。
- **`AWS_SES_REGION`** = 你在哪個 AWS 區域開的 SES,例如 `ap-northeast-1`(東京)。
  SES 是分區域的,填錯區域就找不到你驗證過的網域。
- 帳號密碼不用填 — Amplify 的執行角色會自動帶(SDK 預設憑證鏈)。

**這三個沒設齊 → 寄信全部變成只寫 log,不會壞任何東西。** 所以可以晚點做。
