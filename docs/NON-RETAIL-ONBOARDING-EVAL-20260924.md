# 如果用 MiniMe 的不是店家（2026-09-24）

> 決策紀錄，寫完凍結。狀態一律看 `STATUS.md`（`D-99`）。
> 老闆 2026-09-24：「想評估如果他的 MiniMe 不是店家呢」。

## 一句話結論

**第一題早就問了產業別，但後面全部寫死在「賣東西」。**
一家牙醫診所走這條路，**從第二題就開始答不出來**。
建議不做八套模板，收斂成**三型**：賣東西／做服務／教課，由第一題的答案直接對應。

## 現在已經會照情況換的（不是從零開始）

| 地方 | 照什麼換 |
|---|---|
| 產業別選項 | 本來就有餐飲、美容、教育、服務預約、醫療、旅遊住宿 |
| 歡迎訊息「可以問什麼」 | 照銷售方式：預約制→「想預約時段、問服務內容」；實體→「營業時間、怎麼過來」 |
| 三顆標籤的第三顆 | 預約制→「預約過」；其他→「問過出貨」 |
| 每天早上的節慶提醒 | 用整份輪廓請模型客製，失敗才退回通用句 |

## 寫死在「賣東西」的（問題在這）

| 地方 | 現在長什麼樣 | 牙醫診所看到會怎樣 |
|---|---|---|
| 第 2 題 | 「主要**賣**什麼？」例：黑豆水、養生茶包 | 答不出來，或硬塞一個怪答案——**而那個答案會一路長進 AI 的語氣設定** |
| 第 4 題 | 「客人通常怎麼**買**？」 | 同上 |
| 輪廓卡欄位 | 「主打**商品**」「**價格**帶」「**銷售**方式」 | 卡片是他在精靈裡看最久的一張，一眼看出不是為他做的 |
| 標籤第 1 顆 | 「回購客——**買過**第二次的人」**固定都有** | 用不到 |
| 標籤第 2 顆 | 「**送禮客**／問過**沒買**」 | 用不到。⚠️ 標籤**建了就留在帳號裡**（名字可改、代號改不了） |
| AI 安全規則 | 「價格、**成分**、**出貨天數**這類數字」 | 診所沒有成分與出貨 |
| 知識卡的例子 | 「客人問：**出貨要幾天**？」 | 看完更確定這東西是給網拍用的 |
| 節慶提醒的退路 | 通用句是「**禮盒與送禮**的需求會升溫」 | 客製失敗時退回一句用不到的話 |

## 建議：三型，不做八套

⛔ **八種產業各一套文案＝八份要一起維護的東西，而且切不乾淨**（餐飲跟零售的差別遠小於餐飲跟診所）。

| 型 | 涵蓋 | 名詞 | 三顆標籤 |
|---|---|---|---|
| **賣東西** | 零售／電商、餐飲／飲料 | 商品、價格帶、銷售方式 | 回購客／送禮客／問過出貨 |
| **做服務** | 美容／美業、服務／預約、醫療／健康、旅遊／住宿 | 服務項目、收費區間、接觸方式 | 回訪客／問過沒預約／預約過 |
| **教課** | 教育／課程 | 課程、學費區間、接觸方式 | 續報家長／問過沒報名／問過時段 |

⭐ **「其他（自己打的）」落在中性那一套**：「你主要提供什麼？」「主要項目」。
⛔ **不要猜**——猜錯型比講通用話更傷。

## 為什麼這不是邊緣案例

台灣的 LINE 官方帳號，**服務業與預約制的比重不會比電商低**：
診所、牙醫、美髮、美甲、補習班、健身房、房仲、民宿都在用。

⚠️ **但我們沒有自己的數字**：正式庫目前只有兩個工作區，都是內部帳號，
自助開通的四個也全是測試。所以上面那句是市場常識，**不是我們量到的**。

## 沒做到的

- 本輪只把**精靈這一段**改成三型。後台其他地方仍然到處叫「客人」
  （診所是病人、補習班是學生與家長），那是全站用語，範圍大很多。
- 節慶月曆的**退路通用句**還是「禮盒與送禮」，沒改。
- 旺季選項（年節送禮／夏天／冬天／開學／收假）沒動。⚠️「開學」對補習班剛好，
  但「年節送禮」對診所無意義。

## 三題拍板

1. **收斂成三型** → 建議照做。
2. **「其他」走中性那一套、不猜** → 建議照做。
3. **全站用語（客人／病人／學生）要不要一起換** → 建議**先不要**，
   等有真實的非零售商家再說。⚠️ 那是全站範圍，現在做等於為一個還沒出現的人重構。
