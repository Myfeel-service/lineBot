(來源頁、匯入彈窗、建議收件匣、卡片編輯、各入口)。

## 總結論

問題不是功能不足,而是**這一頁照「系統的資料結構」長,不是照「使用者要做的事」長**。
而答案已經在自己手上:新做的建議收件匣把「讓 AI 學會一題」從**手動 8 步跨 3 頁**壓到
**3 步不跨頁、驗證自動完成**。需要的是把那個模式擴散,並把不該給店家看的東西收掉。

## 量化現況(執行前)

| 成本 | 現況 |
|---|---|
| 學習 | 畫面要求理解約 **95 個名詞**,真正必要只有 **7~9 個**,被迫看到 25~30 個(1:3);**15 組**同一件事不同名字;**16 項**內部實作洩漏 |
| 操作 | 補一題知識:手動 **8 步 / 跨 3 頁**;採用系統建議 **3 步 / 0 跨頁** |
| 流程 | 第一屏 **5 顆工具列按鈕 + 4 層堆疊區塊**(搜尋/AI建議/未分組/體檢六 chip)才看到自己的資料 |

三個維護訊號視覺語言各不相同(橘左條+按鈕 / 灰底+彩色 chip / 灰底+逐項卡片雙按鈕),
使用者無法判斷哪個先做;而其中三項**已經在右下角異常中心裡了**,措辭卻完全不同。

## 執行紀錄(P0 全數完成,typecheck 0 / vitest 701 綠 / SCSS 編譯通過,當時未 commit)

### P0-A 「照著做也修不好」——這組是功能缺陷,不是體驗問題

體檢說「來源同步失敗」時,使用者做完全部正確動作紅字也不會消失。三個獨立原因全修:

1. **gsheet 同步成功不清失敗旗標**:`clearFailure` 定義在 `cron-maintenance.ts:107`,
   但 gsheet 分支在第 94 行就 return——永遠走不到。
2. **url 手動套用變更也不清**,只靠排程下次成功檢查清;而排程只撈
   `refreshIntervalMinutes > 0`,設成「不偵測」的來源永遠卡著。
3. **修好畫面也不更新**:手動同步只重載明細,沒 force 重跑體檢(60 秒快取)。

清除邏輯抽成 `buildSourceClearFailure` / `clearSourceFailure`
(`ai-knowledge-sources.ts`),排程 + 兩支手動端點共用一份,不再各寫一份。

另修兩個結構性死路:

4. **網頁被搬走時可以改網址了**(`PUT /api/ai/sources/:id` 新收 `url`;改網址會一併
   重設 contentHash/pendingHash/outdatedAt 並清失敗旗標,否則拿舊指紋比新網址永遠算錯)。
   以前只能刪掉重建,連帶失去手動編輯過的卡。
5. **失敗畫面可以就地修**:原本只印一行後端英文原文。現在是「⚠ 抓不到內容」+
   白話「該做什麼」+ 修的工具(gsheet 直接顯示服務帳號 email 與複製鈕、url 直接改網址),
   後端原文降級成最後一行小字。

### P0-B 補上我自己的兩個缺口

- **編輯既有卡片看不到「客人問法」**:`openEditChunk` 傳 `questions: undefined`
  (語意=不要動),結果從「補知識」存進去的客人原話(可能夾電話姓名)**永遠改不掉**。
  現在後端 `listChunksBySource` 回傳 questions、編輯時載入,清成空陣列也送得出去
  (原本用 `length` 判斷 → 全部刪掉會送不出去 = 刪不掉)。
- **AI 脈絡卡是 `v-if="isSuperAdmin"`**:所以這次做的「補知識」與「這題 AI 答錯了」
  兩顆按鈕**一般老闆看不到**。這是權限範圍決定(會影響所有租戶),**刻意未動,待拍板**。
  影響:在打開之前,「從答錯學習」這條路只有平台端產得出訊號;自動的 handoff 訊號不受影響。

### P0-C 體驗層七項

1. **頁面終於有一句話說明用途**——知識庫原本是所有 AI 頁面中唯一沒有的
   (打開就是內部名詞「來源」)。改在 `editor-empty`:「這裡是 AI 回答客人的依據…
   **沒放進來的事,AI 不會自己編。**」側欄標題改「你的資料」。
2. **三個提醒收成一條「要處理的事」**:照「會不會影響客人」排序,每項=結論 +
   一句「不管它會怎樣」+ 一顆按鈕(沿用右下角小幫手那套語言)。
   「已過期自動停用」虛線灰階排最後、明說「正常,不用處理」。
   AI 建議草稿要看內容,維持獨立區塊,不在待辦重複列。舊的 orphan banner 與
   體檢 chip 兩套樣式已移除(無孤兒)。
3. **存檔後就地試問**(新端點 `POST /api/ai/knowledge/verify`,isTest 不進統計):
   手動建卡/編輯完會自動用「客人問法(優先)或標題」試問一次並回報。
   以前只有系統建議那條路會自動驗證,手動路徑得換頁自證——同一件事兩種待遇。
4. **匯入預覽改成「摘要 + 主動作先行」**:`.kb-chunk-list` 原本沒有捲動上限而主按鈕
   在最底(同檔的 `.kb-site-list` 卻有 44vh),50 條要捲約一萬像素才按得到 → 沒人真的
   逐條審、只是捲。現在先給摘要+「直接匯入 N 條」,逐條檢查改成點開;並標出
   **含金額/數字的條數**(OCR 提醒說「請逐張確認數字價格」卻沒標是哪幾張,那句話無法執行)。
5. **工具列 5 顆 → 1 顆主按鈕 +「⋯」**。「讓 AI 重新學習全部」是工程維護動作
   (tooltip 原文「系統升級檢索方式後使用」),移進更多並標「(維護用)」。
6. **8 分鐘等待終於有契約**:進度區塊明說「**可以先關掉這個視窗**」、補上取消鈕
   (composable 早就有 `cancel()`,只是這個彈窗沒接)、逾時/失敗改成**留在畫面上的
   錯誤區塊**——原本是 3.5 秒就消失的 toast,等了幾分鐘沒盯螢幕的人回來只看到乾淨畫面。
7. **三個補知識入口行為統一**成開新分頁(監控頁原本同頁跳轉,補完卡沒有回得來的路,
   篩選與捲動位置全部重置)。

### 順便查證的事:180 天刪對話「沒有」掛排程(兩租戶都確認)

`/api/conversations/cleanup` 在程式裡存在,但兩個租戶的 Cloud Scheduler **各只有三個 job**
(warmup / broadcast / maintenance→`/api/cron/run-tasks`),沒有任何一個打它。

所以:
- 對話訊息目前**無限累積**——是成本問題,不是資料遺失風險。
- 「從真人回覆學習」(L3)**不受 180 天窗口限制**,資料都還在。
- ⚠️ **要不要掛上這支排程是老闆的決定**:掛了就會開始真的刪,而 messages 沒有 TTL 欄位
  可以挽回。建議先確認保留多久對業務合適再掛。

## 第二輪:工作台重構(2026-08-04 晚,老闆回饋「還是太複雜」)

P0 修完後老闆仍覺得複雜。這輪的診斷:**240px 側欄同時塞三種工作**
(搜尋 / 異常待辦 / AI 建議收件匣),說明文字句句折行、資料清單被推到摺線以下;
而右側未選取時的大空間只放一段靜態說明——最需要空間的工作擠在最窄的地方,最寬的地方閒著。

全數完成(typecheck 0 / vitest 762 綠 / SCSS 編譯通過,當時未 commit):

1. **工作台**:「要處理的事」+「AI 建議」搬進右側未選取空白區(`.src-workbench`,
   以 `.split-empty-state:has(.src-workbench)` 蓋掉原本的置中排版)。側欄回歸
   「搜尋+資料清單」;選著資料時側欄頂端留一行入口(「N 件要處理、M 個 AI 建議 →」),
   點了回工作台。建議數由 KnowledgeSuggestions `emit('count')` 回報。
2. **待辦單項直跳**(`singleOrList`):最常見情境是隻有一筆壞掉,原本也要過一層
   清單彈窗(彈窗 hint 還把待辦講過的 why 再講一遍);現在單筆直達該筆資料/知識。
3. **看不見的異常補進待辦**:產品別名候選原本只出現在「⋯」選單展開後的項目文字裡,
   ⋯ 按鈕本身無徽章——等於不存在。現在進「要處理的事」(warning)。
4. **異常中心深連結**:兩個知識庫警示帶 `?health=failedSources|failedChunks`,
   到頁自動開對應清單(使用者已按過一次「去修」,不該到頁後再自己找一遍);
   措辭同步對齊(「有資料抓不到內容」「有知識 AI 沒學起來」)。
5. **收件匣空狀態壓縮**:沒建議是最常見狀態,原本仍佔五行(標題+副標+空狀態+掃描列)。
   現在結論寫進標題行,三種狀態誠實區分保留(沒分析過/有缺口但同類還沒重複/都答得出來)。
6. **搜尋不到不再是死路**:空結果加「把這題補進知識庫」,預填搜尋詞為標題與問法——
   問題已打好、也剛確認過沒有重複,是最乾淨的補知識時機。
7. **「信心 0.72」白話化**(AI 脈絡卡已開放到客服層級):改「把握度:很有把握/有把握/
   把握不高」,原始分數留括號小字供平台端排查;與建議收件匣「不印分數」的立場對齊。
8. **手寫視窗收進階**:「標籤/有效期限」收進「進階」摺疊(有值時預設展開,
   不藏生效中的設定),補一題知識預設只看到標題+內容+問法。
