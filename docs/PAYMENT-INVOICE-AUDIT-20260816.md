## 2. 付款（客人買方案）——完整，可以用

### 流程

```
後台按「升級」→ AdminPlanUpgradeDialog（方案比較表）
  → 勾同意條款（不勾不能按；同意版本寫進訂單）
  → 二次確認框（金額／方案／單次 vs 自動續扣／帳單請款名稱 myfeel 揭露／發票會開成什麼）
  → POST /api/payment/create-order → hidden form 自動送出
  → 跳 PAYUNi UPP 託管付款頁（卡號不經過我方）
  → 付完：瀏覽器由 /payuni/return 302 回 billing?order=（只負責顯示）
         開通唯一真相是 /payuni/notify（server→server）
  → billing 頁輪詢 8 次 × 4 秒顯示結果
```

### 做得好的防護（皆程式有實作＋有測試或實測）

- 金額防竄改：Notify 金額 ≠ 建單金額 → 標 failed 不開通（`server/utils/payment.ts:452-456`）。
- 冪等：訂單號＝doc id；paid/failed 終態不重入；expired 但確認已付 → 復活開通（收了錢就給服務）。
- 漏接 Notify：排程主動 `trade/query` 補查，走同一條 fulfill（`payuni-reconcile.ts`）。
- 30 分鐘內同單去重；付款失敗白話原因（「銀行未核准這筆交易」）＋「重新付款」按鈕。
- 開票／收據信接在結算後且吞例外——錢收了不能因開票失敗讓 Notify 回非 200（`payuni-fulfill.ts:62-72`）。
- 手動開通（超管改方案）仍在，只寫資料庫不經金流；清空＝當成免費層 200 則（說明已修正）。

### 缺口

- **付款頁按「取消」沒有返回路**：建單只帶 `NotifyURL`／`ReturnURL`，無任何取消返回參數
  （grep `BackURL`/`ClientBackURL`/`CustomerURL` 全 repo 0 命中）→ `B-40`。
- **未申報的 4,990 方案直接打 API 買得到**：`landingHidden` 只在 UI 層濾掉，
  `create-order.post.ts:25-31` 只擋 `custom` 與 0 元 → `B-39`。
- 首期收款成功但沒拿到卡片 Token（cardBindFailed）只 `console.error`；
  站內警示 `renewalNotBound` 有、主動通知沒有 → 收進 `B-44`⑨。
- ATM／超商代碼付款的 pending 訂單 TTL 3 小時太短（程式註解自承，`payment.ts:538-542`）——目前只收信用卡，未列缺口。
- 「查不到」確認過：獨立 `/pricing`、`/checkout`、付款成功/失敗頁皆不存在（刻意設計：dialog＋302 回帳單頁）。

## 4. 自動扣款——程式 P1~P5 全完成、8/7 端到端實刷全綠，卡在設定

### 整條鏈（程式有實作）

綁卡（首刷建約定拿 CreditHash，只有 `period_first` 才收）→ Cloud Scheduler 每 10 分鐘打
`/api/cron/run-tasks` 的 `billing:reconcile-and-charge` → `chargeDueRecurring`（三層防重複扣款：
claim／冪等訂單號／未決單檢查）→ 成功走 `confirmRenewal`（⛔不能走 buildPaidSubscription，會拿兩個月）→
失敗每日重試一次、3 天寬限期、寬限期滿降回免費層並在那一刻才向 PAYUNi 解約。
折抵蓋滿整期→不呼叫金流、不開發票（`invoiceStatus:'skipped'`）。
客戶端 UI 完整：下次扣款日／金額（含折抵與期末降級）／卡末四碼／取消訂閱／換卡／預約期末降級與反悔。

### 缺口

- 🔴 **線上開關還是關的**（既有 `B-6`）：`PAYUNI_PERIOD_ENABLED` 是 build-time 值，
  `.env_production` 已寫 true 但沒重新部署＝現在客人刷卡都是單次、不建約定、日後無法續扣。
- `.env_production` 三個值會讓上線失敗（既有 `B-22`：`PAYUNI_ENV=test`／RELAY 指沙盒／光貿測試統編）。
- **四種通知信（收據／續訂提醒／扣款失敗／降級）程式寫好但寄不出去**——SES 未開（既有 `B-12`/`B-24`/`B-25`）。
  現況：卡過期的客戶收不到任何信，只有登入後台才看得到警示，否則靜默流失。LINE 推播帳務通知＝查不到（刻意只做 email＋站內）。
- **超管沒有續扣儀表**：無 past_due 清單、無 lastChargeError 彙總、無綁卡數、無手動補扣／代客戶停扣工具 → `B-43`②。
- 帳單頁沒有「向 PAYUNi 即時查卡片約定是否仍有效」（`queryCardBinding` 只用在補開通反查）——GOLIVE-BLOCKERS 曾建議，未做。
- 換卡必伴隨實刷一期（PAYUNi 無 0 元純綁卡，既有 `B-19`）。
- 背景查證：08-04~08-10 有 8 筆只寫 "update" 的 commit 動到金流核心檔（違反本專案 commit 訊息慣例，日後追回歸困難）。
