# 首頁好友名單的示意頭像

首頁 Hero 那張「好友名單」卡片用的人像。放進來就會自動生效，**不用改程式**。

## 怎麼放

**兩步驟**：①把檔案放進這個資料夾 ②把 `app/pages/index.vue` 的 `AVATAR_PHOTOS_READY` 改成 `true`。

第②步不能省：檔案還沒放齊就開啟的話，每次載入都會對不存在的檔案發 6 個請求、
在 console 噴 6 個 404（畫面會靠人形剪影撐住不破版，但那些 404 會一路帶上正式站）。


檔名固定，依名單順序對應（見 `app/pages/index.vue` 的 `FRIENDS`）：

| 檔名 | 對應 |
|---|---|
| `1.jpg` | 陳小姐 |
| `2.jpg` | 王先生 |
| `3.jpg` | 林太太 |
| `4.jpg` | Amy |
| `5.jpg` | 張老闆 |
| `6.jpg` | 蔡小姐 |

- **尺寸**：正方形，建議 144×144（顯示只有 36px，2 倍圖足夠清晰）
- **格式**：`.jpg`（要換 `.webp`／`.png` 的話，改 `FRIENDS` 裡的 `photo` 路徑）
- **構圖**：臉部置中、去背或單純背景。圓形裁切由 CSS 處理，不用自己裁圓

**照片與退路都是 CSS 背景圖層**：照片那一層載不到時不會繪製，底下的人形剪影自然透出來，
所以某一張缺檔也不會破版（但仍會有那一張的 404，建議六張一次放齊再開旗標）。

⛔ 不要改回 `<img>` ＋ `@error` 換圖：圖片是 SSR 出去的，404 會早於 Vue 掛載、
監聽器那時還沒接上（實測完全不生效），而且 Chrome 會在 `alt=""` 的破圖上再畫一個破圖圖示。
